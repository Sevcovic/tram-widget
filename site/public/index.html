Widget pro iPhone a Mac s živými odjezdy z tvé zastávky. Vidíš jízdní řád, skutečný čas i zpoždění. A malou tramvaj, která přijíždí k zastávce.

Jak to funguje

Jízdní řád, nebo skutečnost?

Widget čte otevřená data Prahy (Golemio). Ukáže obojí, a hned vidíš, jestli to stihneš.

Tvoje zastávka, tvoje linky

Kterákoli zastávka PID: tramvaj, bus, metro, vlak. Každá linka má vlastní barvu, ať se 8 a 18 nepletou.

22:21

Skutečný čas a zpoždění

Jakmile spoj vyjede a pošle polohu, uvidíš skutečný odjezd. Do té doby „bez polohy“ a čas z jízdního řádu.

🚋

Tramvaj, která přijíždí

Na iPhonu se tramvajka blíží k zastávce podle toho, kdy jede další spoj. Na Macu přijede při každém obnovení.

Krok 1 · pro iPhone i Mac

Získej API klíč zdarma

Data o odjezdech poskytuje Golemio, datová platforma Prahy. Klíč je zdarma a patří jen tobě; widget ho ukládá jen ve tvém zařízení.

  1. Otevři api.golemio.cz/api-keys

    api.golemio.cz/api-keys ↗

  2. Zaregistruj se e-mailem a potvrď ho

    Stačí jméno, e-mail a heslo. Přijde potvrzovací e-mail.

  3. Vygeneruj klíč a zkopíruj ho

    Je to dlouhý řetězec začínající „eyJ…“. Vložíš ho do aplikace nebo do Scriptable, ne do kódu.

Krok 2

Najdi svou zastávku

Vyber nástupiště podle linek a směru, ať máš správnou stranu ulice. ID se hodí pro iPhone (parametr widgetu); na Macu vybíráš přímo v aplikaci.

Začni psát název zastávky. Diakritika není potřeba.

iPhone

Widget přes Scriptable

Scriptable je bezplatná aplikace, která spouští malé skripty jako widgety. Stačí jeden skript, žádný Xcode.

  1. Stáhni Scriptable z App Store

    App Store ↗ · zdarma

  2. Zkopíruj skript

    V Scriptable klepni na + a vlož celý skript. Pojmenuj ho Tram Widget.

    Stáhnout .js
  3. Spusť ho (▶︎) a vlož API klíč

    Klíč se uloží do Klíčenky v iPhonu. Pak v menu vyber Změnit zastávku a najdi své nástupiště.

  4. Přidej widget na plochu

    Podrž prst na ploše → Upravit → Přidat widget → Scriptable → střední velikost. Klepni na widget a u Script vyber Tram Widget.

  5. Víc zastávek?

    Přidej další widget a do pole Parameter napiš ID nástupiště z kroku 2, např. U906Z3P.

Obnovování: skript si říká o novou verzi každou minutu, ale kdy widget opravdu obnoví, rozhoduje iOS. Obvykle je to každých 5–15 minut. Stáří dat vidíš vpravo nahoře.
Klepnutí na widget otevře Scriptable s čerstvým náhledem.
Tmavý režim se řídí iPhonem. Napevno ho nastavíš změnou THEME na začátku skriptu.

Mac

Nativní widget pro macOS

Aplikace Tram Widget pro macOS 14 a novější. Vybereš zastávku, vložíš klíč a přidáš widget na plochu. V okně aplikace objede tramvaj celý okruh.

GitHub ↗ Zdrojový kód .zip

Podepsaná verze ke stažení se připravuje (čeká na ověření od Applu). Zatím si ji můžeš sestavit sám:

  1. Nainstaluj Xcode a XcodeGen

    Xcode z App Store, pak v Terminálu:

    brew install xcodegen
  2. Stáhni kód a uprav dva řádky

    V project.yml změň DEVELOPMENT_TEAM (Xcode → Settings → Accounts) a BUNDLE_PREFIX, např. com.tvojejmeno.

    git clone https://github.com/Sevcovic/tram-widget
cd tram-widget
  3. Vygeneruj projekt a spusť
    xcodegen generate
open TramWidget.xcodeproj

    V Xcode stiskni ▶︎. V aplikaci vyber zastávku a vlož klíč.

  4. Přidej widget

    Pravý klik na plochu → Upravit widgety → hledej Tram Widget.

FAQ

Časté otázky

Proč se widget neobnovuje každou minutu?

iOS i macOS samy rozhodují, jak často se widgety překreslí, aby šetřily baterii. Obvykle je to každých 5–15 minut. Odpočet minut se ale přepočítává i mezi tím a stáří dat vidíš přímo ve widgetu.

Co znamená „bez polohy“?

Spoj ještě nevyjel z konečné nebo zatím neposlal polohu, takže skutečný čas nikdo nezná. Platí čas z jízdního řádu. Jakmile vyjede, objeví se skutečný čas zeleně (včas) nebo oranžově/červeně (zpoždění).

Stojí to něco?

Ne. Scriptable, Golemio klíč i Tram Widget jsou zdarma. Pokud se ti líbí, můžeš mi koupit kafe.

Kam jdou moje data?

Nikam kromě Golemia. Widget se ptá přímo api.golemio.cz s tvým klíčem, ten zůstává v Klíčence (iPhone) nebo v aplikaci (Mac). Žádný můj server tím neprochází.

Funguje to i pro autobusy a metro?

Ano, pro jakoukoli zastávku PID včetně příměstských autobusů a vlaků. Tramvajka nahoře je jen ozdoba, odjezdy jsou skutečné.
